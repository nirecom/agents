Retired-token registry of check-migration-blocks (#2820). Only the marker range is read.
Line forms (one per line, between the markers):
  # migration <id> <desc-key>     a temporary block whose description holds <desc-key> belongs to <id>
  # scope <id> <glob>             repo-relative path glob, anchored at both ends
  # word <id> <identifier>[@<glob>]  matched on identifier boundaries; @<glob> narrows that token
  # re <id> <regex>[@<glob>]      JavaScript regex, matched per line; @<glob> narrows that token
  # except <id> <path> <reason>   skip <path> for <id>; the reason is mandatory (user-approved only)
Globs: ** spans directories, * and ? stay within one segment, {a,b} is an alternation.
A token is an error outside its migration's temporary block; a registered block needs added and deletion-condition.
