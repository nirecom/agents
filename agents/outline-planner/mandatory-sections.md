# Outline Planner — Mandatory Sections

- Do NOT write `## Issues`; it is carried automatically, and a planner-authored copy is stripped before the final write.
- Do NOT write `## Class members`; read it from intent.md (see `agents/outline-planner/class-members.md`).
- Write `## Accepted Tradeoffs (outline)` yourself, holding only the tradeoffs this outline newly accepts; write the empty marker of `skills/_shared/no-upstream-copy.md` when there are none.
- Never carry intent's `## Accepted Tradeoffs (intent)` (or the legacy `## Accepted Tradeoffs`) into the outline; reference it by section name (`skills/_shared/no-upstream-copy.md`).
- Start your draft from `# <H1 title>`, then `## Adopted approach` / `## Considered alternatives (rejected)` / `## Delivery plan` / `## Accepted Tradeoffs (outline)` and the subsequent sections.
