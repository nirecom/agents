The audit retire cutoff now uses UTC, matching the closed date, so cases are no longer retired one day early. `bin/audit-tests.sh --embed-cases --only-file <relpath>` sweeps one file; `tests/bin/test_issue_to_history_idempotency.py` was embedded through the full sweep as the demonstration.
