# Glossary — agents repository
<!-- lang-check: ignore -->

The glossary is split by category; look a term up in the file for its category.

- [glossary-user.md](glossary-user.md) — terms the user sees directly: skill names, `.env` settings, sentinels, workflow steps, confirmation dialogs.
- [glossary-internal.md](glossary-internal.md) — terms the user never sees but many components reference as design concepts.

A term used by a single subsystem is defined once in its owning document, not here.
Entry criteria, categories, and entry form: [rules/docs/glossary.md](../rules/docs/glossary.md).
